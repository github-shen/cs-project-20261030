# a/b 交换与报文格式

实现对照《第3-4次-层次网络》第 26～36 页：四个节点地位相同，各自持有全域 EPT 和自己的 IFT；入口选择一次出域端口，域内携带 EPID，出域时解封装。拓扑、端口号及示例带宽采用课件图表。

## 地址字段

逻辑地址使用 IPv6 的 128 位地址空间。最高位为 bit 0，`a/b` 选择半开区间 `[a,a+b)`；`32/8` 取第 5 字节。域前缀取 `domain` 的前 a 位，后续位不参与前缀比较。

```text
id 1
ab 32/8
domain 2001:db8::
node 1 2001:db8:ff00::1
node 2 2001:db8:ff00::2
node 3 2001:db8:ff00::3
node 4 2001:db8:ff00::4
```

例如 `2001:db8:0300::1` 的字段值为 3，`2001:db8:0500::1` 为 5；`2001:db9::1` 的前缀不同，属于上行。课件未明确位编号基准，以上 MSB/零起点是本项目采用的明确约定。

C 引擎支持 `0 ≤ a ≤ 127`、`1 ≤ b ≤ 16`、`a+b ≤ 128`，包括跨字节字段。Lport 采用 16 位；65535 保留给上行，不能另作下行号。示例生成器为容纳下行 3/5 及站点编号，限制 `a≥1`、`3≤b≤16`、`a+b≤120`；这些是示例地址规划限制。改变 a/b 时，四个节点与三个信道的配置必须一致。

`node SID IPv6` 是节点诊断地址的全域映射，用于直接验证内部交付。精确命中该地址时使用 `EPID=(SID,0)`；PID 0 是本实现的本节点交付约定，普通外部出口 PID 必须大于 0。

## 全域外部端口表

四个节点配置同一组 EPT。格式为 `ept Lport SID PID Bandwidth Status`；数值为十进制。Status 0 可用，1 停用。带宽作为相对权重，单位只需在各条目间一致。

| Lport | SID | PID | Bandwidth | Status |
|---:|---:|---:|---:|---:|
| 65535 | 1 | 3 | 622 | 0 |
| 65535 | 3 | 2 | 155 | 0 |
| 3 | 2 | 1 | 155 | 0 |
| 3 | 4 | 1 | 45 | 0 |
| 5 | 4 | 5 | 100 | 0 |
| 5 | 3 | 3 | 45 | 0 |

入域处理顺序：

1. 校验格式、精确长度、CRC 和 TTL；外部输入不能自带 EPID。
2. 检查源地址所属的逻辑信道与入口匹配。下行检查域前缀和 a/b 字段；上行要求源地址在域外。
3. 目的在本域内则提取 a/b 字段，否则选择上行 65535。上行进入且目的仍在域外的包拒绝回送上行。
4. 在该 Lport 可用出口中按带宽加权选择 EPID。哈希为完整源/目的 IPv6 地址的 FNV-1a，同一地址对在表状态不变时选择相同出口。
5. 本节点拥有出口则去除 EPID 并外发，否则按目的 SID 查 IFT。

## 内部转发表

格式为 `route SID PID:HOP:Status,...`。例如节点 1：

```text
route 2 1:1:0,2:2:0
route 3 2:2:0,1:2:0
route 4 2:1:0,1:2:0
```

先排除停用端口和停用候选，再选择最小跳数；等跳数候选按地址流哈希分配。本机发送报错时尝试剩余候选，必要时使用更长路径。转发过程中保持入口已选择的 EPID，目的节点才去封装。每次交换转发递减 Hop Limit 并重算 CRC。

内部口只接受配置邻居的 UDP IP/端口，并核对 EPID 是否属于目的逻辑信道的可用出口。静态表不提供分布式状态传播；远端静默故障不会产生本机发送错误。多点故障下 TTL 限制环路寿命，不承诺任意故障都可绕行。

## 实验帧

所有多字节字段采用网络字节序。每个 UDP 数据报或 L2CAP SDU 是一个完整帧：

| 字段 | 字节数 | 含义 |
|---|---:|---|
| HN / version / flags | 4 | `48 4E 01`，flags 0=外部，1=内部 |
| SID / PID / RES | 4，仅内部 | SID、PID 各 1 字节，RES 2 字节必须为 0 |
| IPv6 头 | 40 | Version 6；保留 Traffic Class / Flow Label；Next Header 253；Hop Limit 初始 16 |
| 实验文本 | 0～199 | Payload Length 给出实际字节数 |
| CRC-16/CCITT | 2 | 初值 0xFFFF，覆盖前面所有字节 |

外部帧最大 245 字节，内部帧最大 249 字节。当前实现只处理 Next Header 253 的实验文本；不接管普通 IPv6 TCP/UDP 或扩展头报文。主机和共享信道拒绝域内 EPID，避免封装泄漏到外部。

旧 16 位 `Frame` 保留主机字节序，不能与 a/b 帧互发。`bin/switch` 依据配置的 `ab` 行选择模式；`bin/host` 根据参数是否为 IPv6 地址选择模式。蓝牙适配器支持两种帧格式并按各自精确长度检查，内容及 CRC 原样传递。
